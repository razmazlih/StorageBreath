# תכנון חוויית האחסון — נובמבר 2026

המטרה: להבין מה תופס מקום, להגיע לקובץ, ולבחור פעולה בלי לחפש בין כפתורים בעלי משקל זהה.

## היררכיית המסך

1. ניווט קבוע בצד ימין בחלון רחב (1,000 נקודות ומעלה): כל הקבצים, גדולים, זמניים ו־iCloud. בחלון קטן הניווט עובר לשורת כותרת קומפקטית.
2. כותרת שמציינת את המיקום הנוכחי, מספר הקבצים והנפח שמופו. סריקה היא הפעולה הראשית; בחירת תיקייה והגדרות הן פעולות משניות.
3. חיפוש קבוע מעל הרשימה, עם קיצור Command-F, ספירת תוצאות וסינון. איפוס מופיע כשיש מסנן פעיל.
4. רשימת תוצאות נגללת. פעולות בחירה מופיעות בהתאם לבחירה; הכפתור התחתון מוביל לסקירה ואישור.
5. ב־iCloud שתי מטרות נפרדות עם השלכות גלויות: פינוי עותק מהמק והעברה לפח בענן.

## שפה חזותית

רקע כהה אחיד, משטחים בגוון צפחה, הדגשות טורקיז, כפתורים בגובה 32 נקודות לפחות, נתיבים בקריאות משופרת. הרקע אינו מצייר רשת נקודות או שכבות גרדיאנט בכל גודל חלון. תמיכה בעברית ובנתיבים משמאל לימין נשמרת.

## ביצועים

ספירת קטגוריות וזמניים ללא מסננים נוספים משתמשת בסיכומים המתוחזקים במסד. מסננים והגנות ממשיכים להשתמש בספירה המדויקת. אינדקס קטגוריה וגודל מונע מיון זמני במעבר לקטגוריה. היצירה הראשונה שלו באינדקס קיים עשויה להאריך את טעינת הפתיחה; היא מתרחשת ברקע.

## גבולות האימות

בדיקות המודל משתמשות בנתוני בדיקה ובפעולות ניקוי מדומות. בדיקת ממשק ידנית אינה מבצעת מחיקה בקבצים אישיים. שיפור תוכנית השאילתה אינו הבטחה ליחס האצה קבוע בכל דיסק.
